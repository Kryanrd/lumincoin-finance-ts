# Lumincoin Finance - TypeScript Version

## О проекте

Lumincoin Finance - веб-приложение для учёта личных финансов, позволяющее отслеживать доходы и расходы, управлять категориями операций и контролировать текущий баланс.

Данный проект представляет собой TypeScript-версию клиентской части приложения, первоначально разработанного на JavaScript. Основная задача переноса - адаптация существующей функциональности с использованием статической типизации TypeScript, сохраняя логику и пользовательские сценарии оригинального проекта.

## Функциональность

- **Регистрация и авторизация:** создание аккаунта и вход в систему с использованием электронной почты и пароля.
- **Управление доходами и расходами:** создание, просмотр, редактирование и удаление финансовых операций.
- **Управление категориями:** создание, редактирование и удаление пользовательских категорий доходов и расходов.
- **Контроль баланса:** отображение текущего баланса и его пересчёт при изменении финансовых операций.
- **Финансовая статистика:** визуализация доходов и расходов с помощью круговых диаграмм.
- **Фильтрация по периодам:** просмотр операций за день, неделю, месяц, год, за всё время или выбранный интервал дат.
- **Клиентская маршрутизация:** переход между разделами приложения без полной перезагрузки страницы.

## Особенности TypeScript-версии

- Перенос клиентской логики с JavaScript на TypeScript.
- Использование типов и интерфейсов для описания данных и параметров приложения.
- Типизация маршрутизации и взаимодействия с DOM.
- Использование строгого режима TypeScript (`strict`).
- Сборка и обработка TypeScript-кода с помощью Webpack и ts-loader.

Backend сохранил исходную реализацию на JavaScript и продолжает предоставлять REST API для работы приложения.

## Запуск проекта

Для локального запуска потребуется установленный Node.js и npm.

### 1. Клонирование репозитория

```bash
git clone https://github.com/Kryanrd/lumincoin-finance-ts.git
cd lumincoin-finance-ts
```

### 2. Запуск Backend

В первом терминале перейдите в папку `backendp`:

```bash
cd backendp
```

Установите зависимости:

```bash
npm install
```

Запустите сервер:

```bash
npm start
```

Backend будет доступен по адресу:

`http://localhost:3000`

### 3. Запуск Frontend

Откройте второй терминал в корневой папке проекта и перейдите в `frontend`:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Запустите приложение в режиме разработки:

```bash
npm run dev
```

Frontend будет доступен по адресу:

`http://localhost:9000`

Для корректной работы приложения необходимо одновременно запустить frontend и backend.
